### メモリとエージェントの組み合わせ方

| | パターン A: 自動メモリ | パターン B: ツール型メモリ |
|---|---|---|
| 検索 | 毎ターン、アプリのコードが必ず `search` | LLM が必要と判断したときに `search_memory` ツール |
| 保存 | 毎ターン、会話を `add`（mem0 の LLM が抽出） | LLM が `save_memory` / `update_memory` / `delete_memory` |
| 長所 | 実装が簡単、覚え漏れ・思い出し漏れが無い | 無駄な検索が無い、会話で訂正・削除ができる |
| 短所 | 毎ターンのコスト・レイテンシ | LLM の判断次第で漏れる |
| 実装 | `tutorial/agent.py` `MemoryChatAgent` | `tutorial/agent.py` `ToolMemoryAgent` |

**体験のしかた**: 例文を上から順に送り、途中で「🔄 新しいセッション」を押してから質問してみてください。
会話履歴が空でも、記憶をもとにパーソナライズされた回答が返ってきます。
「メモリを使う」を OFF にすると違いがはっきり分かります。
