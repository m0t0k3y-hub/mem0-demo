## mem0 とは

**mem0（メムゼロ）** は、LLM アプリや AI エージェントに **長期記憶** を持たせるためのライブラリです。

LLM 自体は会話をまたいで何も覚えていません。よくある対処は「会話履歴を全部プロンプトに入れる」ことですが、
長くなるほどコストが上がり、別セッションの内容は引き継げず、古い情報に埋もれて精度も落ちます。

mem0 は会話から **「ユーザーは卵アレルギー」「ユーザーは大阪在住」** のような短い事実だけを抜き出して保存し、
次に必要になったときに **意味検索で関連するものだけ** を取り出します。

```
          会話                              mem0                         次の会話
 ┌───────────────────────┐   add()   ┌───────────────────┐  search()  ┌───────────────────────┐
 │ user: 卵アレルギーで…  │ ────────▶ │ LLM で事実を抽出    │ ─────────▶ │ 関連する記憶だけを     │
 │ assistant: …           │           │ → 埋め込み → 保存   │            │ システムプロンプトへ    │
 └───────────────────────┘           │ (Vector DB+履歴DB) │            └───────────────────────┘
                                     └───────────────────┘
```

### 短期記憶と長期記憶

| | 短期記憶（会話履歴） | 長期記憶（mem0） |
|---|---|---|
| 中身 | 直近のメッセージそのまま | 抽出された事実（1 文ずつ） |
| 範囲 | 今のセッションだけ | セッション・エージェントをまたぐ |
| LLM への渡し方 | messages にそのまま | 関連するものを検索してプロンプトに差し込む |

エージェントは **両方を組み合わせて** 使います（直近数ターン＝履歴、それ以前＝mem0）。

### 主要 API（これだけ覚えれば OK）

| メソッド | 役割 |
|---|---|
| `m.add(messages, user_id=...)` | 会話を記憶する（`infer=False` ならそのまま保存） |
| `m.search(query, filters={"user_id": ...})` | 関連する記憶を検索 |
| `m.get_all(filters={...})` | 記憶の一覧 |
| `m.get(id)` / `m.update(id, text)` / `m.delete(id)` | 1 件の取得・更新・削除 |
| `m.history(id)` | 変更履歴 |
| `m.delete_all(user_id=...)` | スコープ単位の一括削除 |

### スコープ

| ID | 用途 | 例 |
|---|---|---|
| `user_id` | ユーザーの長期記憶 | 好み・属性・目標 |
| `agent_id` | エージェント固有の記憶 | 運用ルール・ノウハウ |
| `run_id` | セッション（短期）の記憶 | 今回の旅行の条件 |
